**Status:**

- **Done**: built, and a test proves it. Where a test isn't practical (timing), a code review, and the Proof column says so.
- **Partial**: some mitigations are built, some are not (the Proof column says which).

## Open items

- Rate limiting: sign-up per IP (row 5), and login 5 wrong tries per email + warning email (row 3). Day 7.
- CSRF: JSON only (415) and the Origin check (403) (row 7, ADR-004). Day 7.
- Forgot password: endpoint and email, same answer for every email, end other sessions, `#token=` link (row 6). Day 7.
- Back button shows the login page (row 1). Day 7, with the pages.
